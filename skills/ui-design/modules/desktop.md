# PC 桌面应用 UI 专项规范

适用：Windows、macOS、Linux 原生或跨平台桌面软件。

## 1. 尊重平台习惯
- Windows 界面应考虑 Fluent 生态中常见的窗口、菜单、工具栏和控件行为。
- macOS 应尊重菜单栏、窗口交通灯、快捷键和更克制的布局惯例。
- 跨平台应用应统一品牌与核心行为，同时保留必要的平台差异。
- 不要把移动端的大卡片和底部 Tab 原样搬到桌面端。

## 2. 窗口与布局
- 明确标题栏、菜单栏、工具栏、主工作区、侧栏和状态栏的职责。
- 窗口可调整大小时，布局应优雅适应；明确哪些区域可伸缩、滚动或折叠。
- 高频操作应容易访问；为复杂工具提供合理的快捷键与右键菜单。
- 支持必要的多选、拖拽、批量操作和键盘操作。
- 信息密度可以较高，但应通过分组、对齐和层级保持可读性。

## 3. 交互与反馈
- 鼠标悬停、按下、焦点、禁用和拖拽状态应清晰。
- 右键菜单与快捷键不能成为唯一操作方式；重要功能应有可发现的入口。
- 长任务应显示进度或阶段；取消行为应明确。
- 对文件覆盖、删除、导出失败等操作提供清楚反馈和合理恢复方式。
- 避免不必要的模态弹窗打断工作流。

## 4. 桌面应用自检
- 测试窗口缩放、最小窗口尺寸和不同 DPI 缩放。
- 检查键盘快捷键、焦点顺序、菜单关闭行为和多窗口情境。
- 确保滚动区域与固定工具栏不会互相遮挡。
- 复杂工作区优先保护主画布或主内容区域。
