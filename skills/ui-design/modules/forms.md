# 表单与设置流程专项规范

适用：注册、登录、结账、资料编辑、复杂设置、数据录入和多步骤流程。

## 1. 减少输入负担
- 只询问完成当前任务所必需的信息。
- 对可推断且风险低的信息合理提供默认值，但不要擅自替用户做高影响决定。
- 选择适当的输入控件；避免让用户手动输入本可安全选择或自动填充的内容。
- 按用户理解方式分组字段，而不是按后端数据结构分组。

## 2. 标签与帮助
- 每个字段都应有清楚标签；占位符不能代替标签。
- 只有在需要解释格式、隐私或后果时才提供辅助说明。
- 输入格式、长度限制和必填要求应在用户需要时可见。
- 错误信息应指出具体字段和修复方法，避免笼统的“输入有误”。

## 3. 验证与状态
- 尽可能在合适时机验证，避免用户尚未完成输入就频繁报错。
- 提交失败时保留有效输入，并将焦点或注意力引导到第一个需要处理的问题。
- 明确显示提交中状态，防止重复提交。
- 处理网络失败、超时、会话过期和服务端验证错误。
- 多步骤表单应说明步骤位置；返回上一步时尽可能保留内容。

## 4. 取消、保存与高影响操作
- 区分保存、应用、提交、关闭和取消的含义。
- 对未保存更改，在必要时提醒用户并提供继续编辑或放弃更改的选择。
- 删除、覆盖、付款、公开发布等高影响操作应清楚说明后果。
- 在合理可行时支持撤销或恢复。
- 不通过隐藏取消按钮或误导性按钮层级迫使用户继续。

## 5. 表单自检
- 键盘类型、自动填充和焦点顺序是否合理？
- 标签、提示与错误是否清楚关联？
- 失败后是否保留输入？
- 提交中是否防止重复操作？
- 用户是否能理解如何取消、返回或恢复？
