# 营销页与产品介绍页专项规范

适用：产品官网、功能介绍、活动落地页、服务介绍和转化页面。

## 1. 首屏职责
- 首屏应快速说明产品是什么、为谁解决什么问题。
- 使用一个主要行动号召；次要入口应明显降低视觉权重。
- 不用空洞的大标题代替清楚的价值主张。
- 视觉素材应真实支持产品定位，不使用与功能无关的装饰图填充空间。

## 2. 内容顺序
根据产品与用户决策路径组织内容，常见结构包括：
1. 价值主张与主要 CTA
2. 核心能力或使用方式
3. 真实的产品界面或工作流程
4. 可信的证据、限制或适用场景
5. 常见疑问与后续行动

这只是参考，不应强制每个页面采用相同区块顺序。

## 3. 可信度与文案
- 不虚构客户评价、用户数量、奖项、案例、数据或认证。
- 避免夸大、虚假紧迫感和误导性承诺。
- 说明重要限制、适用条件和价格信息（若相关）。
- CTA 应描述用户将要执行的动作或得到的结果。
- 避免连续堆叠同等级标题、按钮和卡片。

## 4. 视觉与性能
- 建立有辨识度但克制的品牌视觉系统。
- 动效用于解释关系、展示过程或提供反馈，不应阻碍阅读。
- 图片与视频应考虑尺寸、加载性能、替代文本和移动端裁切。
- 移动端首屏应保留价值主张与关键操作，不应只剩装饰图。

## 5. 营销页自检
- 用户是否能在短时间内理解产品价值？
- 主要 CTA 是否清晰且唯一占优？
- 所有可信度声明是否有真实依据？
- 页面是否避免模板化区块堆叠和无意义营销文案？
