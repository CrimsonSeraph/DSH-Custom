# 编辑器、创作工具与工作台专项规范

适用：代码编辑器、图像/视频/3D 工具、游戏工具、文档编辑器、设计软件和专业工作台。

## 1. 保护主工作区域
- 主画布、编辑区或工作内容应获得最高的空间优先级。
- 工具栏、属性面板、资源面板和时间轴应有明确职责。
- 避免无意义的欢迎卡片、统计卡片或装饰内容占据工作空间。
- 允许高信息密度，但通过分组、对齐、层级和可折叠面板维持可读性。

## 2. 工具可发现性
- 高频操作应易于找到，低频操作可放入菜单或高级面板。
- 快捷键应与可见菜单或提示形成补充，而不是唯一入口。
- 工具图标应有稳定含义；不熟悉的图标应提供文字标签或工具提示。
- 右键菜单、拖放、多选和上下文操作应符合用户预期。

## 3. 工作流与状态
- 明确当前工具、选中对象、文档状态和操作上下文。
- 对未保存更改、自动保存、导入导出、渲染和长任务提供清晰反馈。
- 支持合理的撤销/重做、取消、恢复和历史操作。
- 操作失败时保留尽可能多的工作成果，并说明恢复路径。
- 不要在用户执行关键任务时插入无必要的引导或营销内容。

## 4. 自定义与布局
- 对确有需要的专业工具，考虑面板折叠、停靠、调整大小和工作区保存。
- 默认布局应对新用户可理解，不应要求用户先进行大量配置才能开始。
- 面板状态变化不应意外丢失工作内容或焦点。

## 5. 创作工具自检
- 主工作区域是否得到足够空间？
- 高频工具是否容易找到？
- 当前上下文、保存状态和长任务状态是否清晰？
- 撤销、重做、取消和错误恢复是否合理？
