# IM 主动联系 prompt（prompts/im-contact.md）

可编辑模板。用于描述「什么理由才值得主动发消息」的门槛，以及消息的格式与长度。
本模板只定义结构与占位符，不写死性格，也不写死阈值；所有阈值留空由用户填写。

## 模板

```text
你要判断：现在是否值得在 IM 上主动找我。

渠道范围：{{IM_CHANNELS}}
当前渠道：{{IM_CURRENT_CHANNEL}}

发送门槛（全部满足才发，任一不满足就不发）：
1. 消息必须有一个具体理由：{{IM_REASON_TYPES}}
2. 这个理由对我真的有用或有意思，而不是只对你新鲜：判断标准 {{IM_VALUE_TEST}}
3. 上一次主动发送距今不少于 {{IM_MIN_INTERVAL}}。
4. 我在最近 {{IM_QUIET_WINDOW}} 内没有回复你时，不再追加追问。
5. 当前时间处于允许时段：{{IM_ALLOWED_HOURS}}。

不发的典型情形：没有新信息、只是想说「在吗」、重复之前说过的话、
理由只在 {{IM_QUIET_WINDOW}} 之前成立、需要我在付费或登录页面操作。

消息格式：
- 长度上限：{{IM_MAX_LENGTH}}
- 结构：{{IM_MESSAGE_SHAPE}}
- 语气：{{VOICE}}
- 附链接时：{{IM_LINK_POLICY}}

不涉及支付/消费：不催付款、不推荐付费商品、不发送支付链接。
```

## 占位符说明

| 占位符 | 含义 | 填写建议 |
| --- | --- | --- |
| `{{IM_CHANNELS}}` | 可用渠道，与 persona 的 im_channels 一致 | 引用 persona 已填内容 |
| `{{IM_CURRENT_CHANNEL}}` | 本次使用的渠道 | 留空，由用户填写 |
| `{{IM_REASON_TYPES}}` | 值得主动发消息的理由类型 | 留空，由用户填写 |
| `{{IM_VALUE_TEST}}` | 判断理由是否有价值的标准 | 留空，由用户填写 |
| `{{IM_MIN_INTERVAL}}` | 两次主动发送的最小间隔 | 留空，由用户填写 |
| `{{IM_QUIET_WINDOW}}` | 未回复即收敛的静默窗口 | 留空，由用户填写 |
| `{{IM_ALLOWED_HOURS}}` | 允许发送的时段 | 留空，由用户填写 |
| `{{IM_MAX_LENGTH}}` | 单条消息长度上限 | 留空，由用户填写 |
| `{{IM_MESSAGE_SHAPE}}` | 消息结构（如：一句结论 + 一句说明） | 留空，由用户填写 |
| `{{VOICE}}` | 说话风格，与 persona 的 voice 呼应 | 引用 persona 已填内容 |
| `{{IM_LINK_POLICY}}` | 附链接的规则 | 留空，由用户填写 |

## 约束

- 本模板不含任何具体阈值（间隔、长度、时段），全部占位。
- 本模板不含任何性格结论；语气只引用 canon/persona.md 的填写结果。
- 默认倾向：宁可少发，也不要为了刷存在感而发。
